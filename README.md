## A Browser Add-On to Automatically Translate Web Texts into German Easy Language: Leichte Sprache - Überall

"Leichte Sprache - Überall" is a Chrome browser add-on designed to translate any text on a webpage into German "Leichte Sprache" (Easy Language). Based on German Easy Language guidelines, this extension aims to make web content more accessible to people with cognitive impairments.

## Features

The add-on utilizes LLMs via API to automatically translate the content of a webpage.
Currently, the user has to configure the following settings via the add-on's popup:
- the API key, 
- the API to be used (Groq Cloud, OpenAi)
- the model to be used (e.g. LlaMA, GPT-4o)
 
For each website, translations are cached in the browsers local storage, which can be manually accessed DevTools->Application->Storage->Local Storage


## Browser Add-On Setup

1. Clone the Repository
2. Execute the `npm run build` command (this creates the `dist` directory)
3. Visit [Chrome Extensions](chrome://extensions/) and enable **Developer Mode**
4. Upload the `dist` directory to your Chrome Extensions via **Load Unpacked**
5. Open the add-on's popup to configure the settings

### Readability Evaluation
The `readability evaluation` directory contains code and all `json` files relevant for evaluating the translations generated by the browser add-on. A detailed evaluation on the calculated metrics can be found in the Thesis provided in this repository.
